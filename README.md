# FilePilot

Lekki program na Windowsa, który automatycznie porządkuje pliki w folderach *Pobrane* i *Pulpit*.

## Funkcje

* **Automatyczne sortowanie:** Rozdziela nowe pliki do odpowiednich folderów zaraz po ich pobraniu.
* **Cicha praca w tle:** Zminimalizowany do zasobnika systemowego (System Tray), nie obciąża procesora ani pamięci RAM.
* **Dopasowany interfejs:** Ciemny motyw zaprojektowany pod wygląd Windowsa.
