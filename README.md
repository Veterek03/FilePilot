
# FilePilot

Lekki i wydajny asystent dla systemu Windows, który w tle automatycznie dba o porządek w Twoich plikach.

---

### 🌟 Funkcje
* 📁 **Automatyczne sortowanie:** Pliki z folderów Pobrane i Pulpit trafiają do odpowiednich katalogów zaraz po pobraniu.
* ⚡ **Praca w tle:** Działa dyskretnie w zasobniku systemowym (System Tray) i nie obciąża komputera.
* 🎨 **Nowoczesny wygląd:** Ciemny motyw w pełni dopasowany do stylistyki Windowsa.

---
