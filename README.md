# 📁 FilePilot

Lekki i wydajny asystent dla systemu Windows, który w tle automatycznie dba o porządek w Twoich plikach.

---

## 🌟 Funkcje

* **Automatyczne sortowanie:** Pliki z folderów *Pobrane* i *Pulpit* trafiają do odpowiednich katalogów zaraz po pobraniu.
* **Bezpieczeństwo przeglądarek:** Silnik rozpoznaje pliki tymczasowe (`.crdownload`, `.part`, `.tmp` itp.) i czeka na pełne dokończenie pobierania przed przeniesieniem.
* **Cicha praca w tle:** Aplikacja działa dyskretnie w zasobniku systemowym (System Tray), nie obciążając procesora ani pamięci RAM.
* **Pełne cofanie zmian (Undo):** Jednym kliknięciem przywrócisz posortowane pliki z powrotem do folderu źródłowego.
* **Nowoczesny interfejs:** Ciemny motyw w stylu Glassmorphism dopasowany do stylistyki systemu Windows, wyposażony w animowany wskaźnik postępu na żywo.
* **Ochrona podfolderów:** Silnik kategoryzuje wyłącznie pojedyncze pliki, pozostawiając Twoje własne foldery nietknięte.
